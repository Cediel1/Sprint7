# Sprint7
## Proyecto del sprint 7
### Descripción
Se creó una app que permite ver histograma, diagrama de dispersion y mapa de calor de la corrrelación de las variables tomadas de la base de datos 'vehicles_us.csv', esta base de datos contiene 51525 registros de anuncios de venta de vehiculos de segunda mano en EE.UU.

### Funcionalidades
El usuario puede elegir que variables a graficar en el histograma y en el grafico de dispersión al igual que el rango si se eligen las variables númericas.

### Cómo ejecutar la app localmente
1. Clonar el repositorio.
2. Instalar las librerías necesarias: pip install -r requirements.txt
3. Ejecutar la app: streamlit run app.py
